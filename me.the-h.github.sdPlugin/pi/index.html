All buttons

Counts only open pull requests in these organizations (comma-separated; leave empty for all of GitHub). Set Organizations on this button only to override the shared list. Leave Token empty to use gh auth login's account; otherwise use a token that can read the organization's repositories and teams (classic: repo, read:org), authorized for SSO if the organization uses it. The token is stored in plain text in deckd's plugin data.

Draft pull requests are never counted. Press a key to refresh it. On a dial, turn to step through the PRs; push or tap the strip to refresh.
