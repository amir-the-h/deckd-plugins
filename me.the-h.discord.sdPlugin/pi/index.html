Discord app (all Discord buttons)

Status: …

Discord only allows voice control for apps you own, so this needs your own (free) app:
  1. Open discord.com/developers/applications and create an application.
  2. Under OAuth2, copy the Client ID and reset/copy the Client Secret into the fields above.
  3. Under OAuth2 → Redirects, add http://localhost.
  4. With Discord open, an “Authorize” prompt appears in it once; accept it.
The secret and sign-in token are stored in plain text in deckd's plugin data.
