Position picks a session in the order they started: 1 is the oldest still running, 2 the next, and so on. On a dial it's where turning starts. Account limits the button to one Claude Code login by its config folder, e.g. ~/.claude or the folder you set in CLAUDE_CONFIG_DIR.

Sessions only show up once Claude Code runs this plugin's hook; see the plugin's README. Pressing brings the session up: its tmux window and pane are selected, and on Hyprland its terminal window is focused.
