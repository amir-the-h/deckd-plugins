Each {name} is replaced by that element's text on the display; the element names are in the list "Write display list" makes (a DCS Status button's settings).

One button per line (or comma-separated): its control id, then = and the name to show. Control ids are in the hint under the control list of a Cockpit Switch's settings.

Show text from a cockpit display

Shows text from a cockpit display (for example a radio channel on the UFC) instead of the control's position. A display is a name from the aircraft's overlay (ufc) or a number. "Lit while" lights the key while that element shows anything, like an option window's selection colon. Use "Write display list" in a DCS Status button's settings while flying to see the ids and element names your aircraft has.

Numbers are DCS's own input commands (the ones listed in Scripts/Export.lua in the game folder). Put two of these in one slot with the tap and hold gestures to get, say, IDLE on a tap and OFF on a hold.

The hook is a small script in Saved Games/DCS/Scripts/deckd/, loaded by one line added to Scripts/Export.lua; any other export scripts there keep working. Removing it takes out only that line and folder. Restart the mission after installing.
