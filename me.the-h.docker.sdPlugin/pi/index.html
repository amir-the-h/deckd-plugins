All buttons

The address is a Docker socket (unix:///var/run/docker.sock), a Docker API URL (e.g. a socket proxy), or your Portainer URL together with a Portainer access token (My account → Access tokens). The token is stored in plain text in deckd's plugin data, readable only by you. Ignored containers (comma-separated names) don't count as down while stopped.

Press a stack or container to stop it when anything in it runs, or start it when it's all stopped (or set Press to refresh). Hold for a second to restart it. On a stack dial, turn to pick the whole stack or one container first. Containers that share another container's network (like a VPN gateway) start after it, stop before it and are restarted with it. The Portainer container the plugin connects through is never stopped. Leave the slot's gestures unset so the plugin can time the hold.
